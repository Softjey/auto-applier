KIM JESTEŚMY?

ALTEN – Światowy lider usług inżynieryjnych i IT

Grupa ALTEN, założona w 1988 roku we Francji, jest wiodącym partnerem technologicznym, obsługującym największych klientów na świecie. W 2023 roku osiągnęła przychody przekraczające 4,07 miliarda euro i zatrudnia ponad 57 000 pracowników, w tym 88% inżynierów i ekspertów IT. ALTEN Polska działa od 13 lat, wspierając innowacje, badania i rozwój oraz systemy IT swoich klientów. Posiada biura w Krakowie, Warszawie, Wrocławiu, Gdańsku i Poznaniu. Obsługuje kluczowe branże, takie jak lotnicza, kosmiczna, przemysłowa, motoryzacyjna, kolejowa, energetyczna, finansowa, telekomunikacyjna i sprzedażowa. Zakres ekspertyzy: analiza biznesowa, cyberbezpieczeństwo, sztuczna inteligencja, analiza danych i rozwiązania chmurowe, rozwój aplikacji, testowanie oprogramowania, zarządzanie projektami, oprogramowanie wbudowane, zarządzanie jakością, industrializacja, transformacja cyfrowa oraz inżynieria przemysłowa.

Więcej informacji na http://www.altenpolska.pl

Poszukiwany: Senior Full Stack Engineer (React + Java/Node.js)

Do globalnego zespołu produktowego poszukujemy Senior Full Stack Engineera, który będzie rozwijać nowoczesną platformę SaaS wykorzystywaną przez największe organizacje na świecie. To rola dla osoby, która dobrze odnajduje się zarówno po stronie frontendu, jak i backendu, a jednocześnie lubi pracować nad złożonymi produktami enterprise. Na co dzień będziesz tworzyć portale administracyjne, dashboardy operacyjne oraz rozwiązania wspierające zarządzanie procesami i konfiguracją platformy w środowisku chmurowym.

KLUCZOWE ZADANIA:

- Projektowanie i rozwój nowoczesnych aplikacji webowych w oparciu o React i TypeScript
- Budowa portali administracyjnych, dashboardów oraz narzędzi wspierających operacje biznesowe
- Tworzenie i rozwój usług backendowych oraz REST API
- Integracja aplikacji z systemami wewnętrznymi i zewnętrznymi
- Praca w architekturze mikroserwisowej
- Współpraca przy projektowaniu nowych funkcjonalności i decyzjach architektonicznych
- Dbanie o jakość kodu poprzez code review oraz testy jednostkowe
- Optymalizacja wydajności, bezpieczeństwa i dostępności aplikacji
- Współpraca z zespołami produktowymi i inżynieryjnymi w międzynarodowym środowisku

WYMAGANIA:

- Minimum 5 lat doświadczenia w tworzeniu aplikacji Full Stack
- Praktyczne doświadczenie z React, TypeScript oraz JavaScript
- Znajomość Java (Spring Boot) lub Node.js
- Doświadczenie w tworzeniu i integracji REST API
- Dobra znajomość architektury mikroserwisowej
- Doświadczenie w pracy z bazami danych relacyjnymi (PostgreSQL, MySQL lub Oracle)
- Znajomość środowisk chmurowych: AWS, Azure lub GCP
- Doświadczenie z Dockerem oraz Kubernetes
- Znajomość CI/CD i systemów kontroli wersji (Git)
- Rozumienie zagadnień związanych z bezpieczeństwem aplikacji oraz uwierzytelnianiem użytkowników (OAuth2, OIDC, SAML, RBAC)
- Bardzo dobra znajomość języka angielskiego
