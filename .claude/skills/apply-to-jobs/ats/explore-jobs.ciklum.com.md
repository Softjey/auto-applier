# Ciklum careers (Oracle Recruiting Cloud, explore-jobs.ciklum.com)

No account: "Apply Now" -> e-mail + mandatory privacy tick -> Next -> 6-digit code mailed
by Ciklum Career (read it from the user's mailbox when a read-only connector exists) ->
single-page form. The candidate profile persists per e-mail, so a second application
**arrives prefilled including the previous vacancy's resume**: press "Remove Resume" (use
the element ref, a coordinate click did nothing) and upload this vacancy's CV into the
"Upload Resume" file input; the page says "Your resume was changed". Address line 1 is
required once Country is set. Skills: tick the job's preferred ones you rate 4+.
Success: My Applications lists the job with "Applied on <date>".
